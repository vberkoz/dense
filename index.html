Core Architecture

4 PILLARS · ZERO BUILD
01 · Vanilla Stack
NO NPM

Pure HTML5, CSS3, and ES6+ with zero frameworks, bundlers, or transpilers. Opens natively over file:// and static HTTPS hosts.

02 · light-dark() Tokens
CSS4

Single-declaration surface, border, and semantic color tokens bound to meta[name="color-scheme"] and persisted in localStorage['ds-scheme'].

03 · Ultra-Condensed
26PX TH

Tight 36px topbars, 22px–30px table headers, tabular-nums slashed-zero alignment, and container-query mobile card transforms.

04 · Native Primitives
TOP-LAYER

Built on <dialog> modals/drawers, Popover API menus and toasts, APG custom selects/comboboxes, and / search hotkeys.

Quickstart

DROP-IN STATIC ASSETS
HTML5 BOILERPLATE src/ds.css src/ds.js src/picker.css + src/picker.js 
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="color-scheme" content="dark">
  <script>try{document.querySelector('meta[name="color-scheme"]').content=localStorage.getItem('ds-scheme')||'dark';}catch(e){}</script>
  <link rel="stylesheet" href="src/ds.css">
  <link rel="stylesheet" href="src/picker.css">
</head>
<body>
  <!-- Use .app, .topbar, .panel, .kpis, .dt, <dialog>, and data-action="theme" -->
  <script src="src/ds.js"></script>
  <script type="module">
    import { initPickers } from './src/picker.js';
    initPickers();
  </script>
</body>
</html>
